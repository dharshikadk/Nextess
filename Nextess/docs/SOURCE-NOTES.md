# Source Notes

## Supplied project specification

The source describes Nextess as a real-world engineering/problem-solving learning system with persistent cases, information/report files, interactive simulation, consequence feedback, 3–4 connected problems per level, hints, try-again/show-answer behavior, explanations, level summaries, and an investigation loop.

## Supplied frontend specification

The source describes five main pages: Home, Streak, Profile, Settings and About. It specifies XP/coins/streak displays, Physics and Economics as active subjects, other subjects as Coming Soon, pastel styling, combined leaderboard/badges/streak experience, project investigations, files shown throughout a level, tables rendered accurately, Physics simulations with variable controls, instructions beside files/simulation, and Back/Next navigation.

## Important gap

The supplied sources do not contain a complete existing repository, backend implementation, database schema, deployment configuration or authentication implementation. Those parts of this blueprint are therefore proposed architecture, not claims about existing code.
