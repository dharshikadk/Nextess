# Nextess Frontend V2

This is the approved UI source moved into a separate folder. The existing `frontend/` directory is intentionally untouched.

V2 uses the real-data API at `VITE_API_BASE_URL` (default `http://localhost:4000`). Authentication, profile, rewards, streaks, badges, directives and leaderboard state are server-backed. Mission catalogue content is sourced from the repository mission package; answer keys are not shipped to the browser.
