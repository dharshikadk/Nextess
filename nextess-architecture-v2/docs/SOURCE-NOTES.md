# Source Notes

The supplied Nextess specification describes the real-world case/investigation model: persistent situation, information files, interactive simulation, variable controls, consequence feedback, 3–4 connected problems per level, hints, retry/show-answer, explanations and level summaries.

The supplied frontend specification describes five main pages—Home, Streak, Profile, Settings and About—plus project investigation, Physics simulation, Economics, XP/coins/streak, badges/leaderboard, files, tables and Back/Next navigation.

New product requirement added on 2026-09-09:

`Open Nextess → Start Exploring → Experience the UI/UX → Try Projects → Decide whether to create an account`

Login/signup must be available at any time but must not be a mandatory first-screen gate.

The supplied files do not constitute a complete existing backend/repository, so backend/database/security details in this architecture are proposed implementation decisions.
