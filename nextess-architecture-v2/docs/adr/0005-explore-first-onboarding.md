# ADR 0005 — Explore-First, Account-Optional Onboarding

Status: Accepted

## Decision

Visitors can open Nextess, start exploring, experience the UI/UX and try eligible projects before deciding whether to create an account.

Login/signup is available at any time but is not a mandatory first-screen gate.

## Reason

The user should understand the product and its investigation experience before committing to an account.

## Consequence

The architecture must support anonymous sessions, anonymous-accessible content, rate limiting and clear authorization boundaries between anonymous and authenticated capabilities.
