# Recommended Repository Skeleton

```text
nextess/
├── apps/
│   ├── web/
│   └── api/
├── packages/
│   ├── contracts/
│   ├── validation/
│   ├── evaluation/
│   ├── simulation-core/
│   └── ui/
├── prisma/
├── content/
│   ├── physics/
│   └── economics/
├── tests/
├── infra/
├── docs/
└── .github/
```

Keep UI, domain evaluation, simulation math, database access and content authoring separated.
